# Logo Project – Bezier Curves

This project showcases a custom **logo design created using Bezier curves**. The logo is displayed as a web-based visual hosted with **GitHub Pages**.

🔗 **Website preview:**  
https://tadejhumar123456789.github.io/Logo/

---

## 📌 About the Project

The main goal of this project is to demonstrate how **Bezier curves** can be used to create smooth, scalable, and visually appealing logo shapes directly on the web.

Bezier curves are commonly used in:
- Vector graphics
- Logo design
- SVG paths

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Bezier Curves
- Svg
